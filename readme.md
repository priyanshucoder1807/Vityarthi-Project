# Campus Health Care Management Platform

A robust, terminal-based healthcare administration and scheduling tool developed using Python 3.

---

## Technical Highlights

* **OOP Architecture:** Built with clean separation of concerns using Student, Appointment, and HealthCentreManager models.
* **Conflict-Free Scheduling:** Employs an instant verification engine that prevents double-booking for any clinical specialty, date, and time slot combination.
* **Structured Console UI:** Outputs receipts, master rosters, and fee lists in formatted text layouts.
* **Crash-Resistant Inputs:** Comprehensive validation loops safely manage unexpected data types, out-of-range ages, 10-digit telephone checks, and invalid date formats.

---

## How to Run

1. Open your terminal or shell in the repository folder.
2. Launch the application:
```bash
python health_system.py

```


3. Follow the numbered terminal menu to register student details, check department fees, or schedule consultations.
